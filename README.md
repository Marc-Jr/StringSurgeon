 
# StringSurgeon

**StringSurgeon** is a Java-based console application that provides a suite of common string utilities, designed for beginner to intermediate Java programmers and students.

## Features

- ✅ **Check Palindrome**  
  Cleans and checks whether a string is a palindrome (supports mixed cases and ignores spaces/punctuation).

- 🧩 **Compress String**  
  Implements basic string compression (`aabcccccaaa` → `a2b1c5a3`). Returns original if compression is not shorter.

- 🔁 **Reverse Sentence Words**  
  Reverses the entire sentence as a string using `StringBuilder`.

- 🔇 **Remove Vowels**  
  Removes all vowels from the input string (case-insensitive).

- 🔐 **Validate Password**  
  Checks if a password meets strong requirements:
  - 8–20 characters
  - At least one uppercase letter
  - At least one lowercase letter
  - At least one digit
  - At least one special character
  - No spaces

## 🚀 How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/Marc-Jr/StringSurgeon.git
   cd StringSurgeon
   ```

2. Compile and run:
   ```bash
   javac StringUtilities.java
   java StringUtilities
   ```


## 📚 Requirements

- Java 8 or later
- Terminal/Command prompt
